# Pokémon Adventure RPG — Beta

Console RPG sederhana untuk belajar C#. Beta ini berisi loop permainan inti:

- Membuat trainer dan memilih Bulbasaur, Charmander, atau Squirtle.
- Menjelajahi Route 1 dengan encounter Pidgey dan Rattata.
- Bertarung secara turn-based: move, akurasi, kecepatan, critical hit, dan efektivitas tipe dasar.
- Menangkap Pokémon, mengelola party (maksimum 6) dan storage.
- Mendapat EXP, naik level, dan mempelajari move baru.
- Menggunakan Poké Ball dan Potion di battle, menyembuhkan party di Pokémon Center.
- Melihat Party, Bag, Pokédex, serta menyimpan/memuat permainan.

## Menjalankan game

Jalankan perintah berikut dari folder proyek:

```powershell
dotnet run
```

Pilih **Save Game** dari menu utama untuk membuat `save.json` di folder saat game dijalankan. Fitur yang belum ada pada beta: evolusi, gym, trainer battle, area lanjutan, dan cerita sampai Champion.
